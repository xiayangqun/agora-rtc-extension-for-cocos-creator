# Converter Generation Scripts

## Two Key Scripts

### `scripts/generate-native-tosevalue.js`
- **Purpose**: Scans Agora SDK C++ headers and auto-generates `nativevalue_to_se` converters (C++ → JS)
- **Output**: `native/agora/RtcNativeValueToSe.h` and `native/agora/RtcNativeValueToSe.cpp`
- **Run**: `npm run genbindings:native-tosevalue` or `node scripts/generate-native-tosevalue.js`

### `scripts/generate-sevalue-to-native.js`
- **Purpose**: Scans Agora SDK C++ headers and auto-generates `sevalue_to_native` converters (JS → C++)
- **Output**: `native/bindings/manual/jsb_agora_rtc_ext.h` and `native/bindings/manual/jsb_agora_rtc_ext.cpp`
- **Run**: `npm run genbindings:sevalue` or `node scripts/generate-sevalue-to-native.js`

## CRITICAL WARNING

**Files generated by these scripts are COMPLETELY OVERWRITTEN on every run.** Direct edits to generated code will be lost when the scripts are re-run.

## Correct Modification Methods

### 1. Use USER CODE BLOCK

Both `.h` and `.cpp` files contain `// USER CODE BLOCK START` and `// USER CODE BLOCK END` markers. Code placed between these markers is preserved across regenerations.

```cpp
// USER CODE BLOCK START
// Your custom converter declarations/implementations go here
bool sevalue_to_native(const se::Value &from, MyCustomType *to, se::Object *ctx);
// USER CODE BLOCK END
```

### 2. Use `// do not gen code cover it` Marker

To prevent a specific generated converter from being overwritten, add this comment directly above it:

```cpp
// do not gen code cover it
bool sevalue_to_native(const se::Value &from, MyType *to, se::Object *ctx) {
    // custom implementation
}
```

### 3. Fix the Script Itself

If the generated code has systemic issues (wrong namespaces, missing types), modify the `scripts/generate-*.js` scripts themselves rather than editing the generated files.

## Common Issues

### Generated converters for non-existent types

The scripts attempt to generate converters for all types found in SDK headers, but some types may not exist in the current platform's SDK version. Solutions:
- Add/remove declarations manually in `USER CODE BLOCK`
- Or modify the script's filtering logic

### Wrong namespace

The script may infer incorrect namespaces (e.g., `agora::UserInfo` should be `agora::rtc::UserInfo`). Solutions:
- Add correct namespace declarations in `USER CODE BLOCK`
- Or modify the script's namespace resolution logic

### Missing header includes

The generated `.h` file may need additional `#include` directives for certain type definitions. Solutions:
- Add needed includes in `USER CODE BLOCK`
- Or modify the script's include generation logic
